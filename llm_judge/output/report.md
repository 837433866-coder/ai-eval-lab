# LLM-as-judge 校准与偏差报告

裁判模型：`judge-v2`　被测模型：`target-v1`

> 硬规则：裁判模型必须与被测模型不同。相同模型会触发自我偏好，评分不可信。

> 阅读顺序：第 1 节是**上线用的无偏差裁判**，已通过校准。第 2~4 节**故意注入强偏差**，目的是证明三种检测器真能抓出偏差——显示「存在偏差」是预期结果，不是缺陷。

## 1. 黄金集校准

- 样本数：20（15 正常 + 3 幻觉 + 2 正确拒答）
- 平均绝对误差 MAE：**0.528**
- ±1 分一致率：**0.75**（阈值 ≥ 0.7）
- Cohen's kappa：**1.0**（阈值 ≥ 0.60）
- 结论：**校准通过，裁判可用**

## 3. 长度偏好测试

| 裁判 | 短答案 | 长答案（内容相同） | 差值 |
|---|---|---|---|
| 无偏差 | 3.225 | 3.25 | 0.025 |
| 注入长度偏差 | 3.225 | 3.85 | 0.625 |

结论：**存在长度偏好，长答案无端得高分**

## 4. 自我偏好测试

- 标成裁判自己模型：4.96
- 标成被测模型：4.46
- 差值：0.5
- 结论：**存在自我偏好，印证裁判必须与被测模型不同**

## 裁判上线的三个必要条件

1. 裁判模型与被测模型**不同**（本报告用 judge-v2 评 target-v1）
2. 用人工标注黄金集校准，一致率和 kappa 都达标才放行
3. 位置 / 长度 / 自我三种偏差测试通过；不通过就做双向评测、长度归一化、强制换模型

> 面试点：只会说'用大模型打分'是初级。能说出裁判偏差、黄金集校准和 kappa，才说明真做过评测。
