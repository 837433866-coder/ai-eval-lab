## 怎么归因

1. **召回率 FAIL、精确率 FAIL** → 知识库或切分有问题，先查文档有没有入库、块是不是切碎了。
2. **召回率 PASS、精确率 FAIL** → 召回了但排序差，上重排模型。
3. **忠实度 FAIL** → 答案里有上下文不支持的内容，即幻觉；也可能是知识库混入冲突文档。
4. **答案相关性 FAIL** → 召回对了但答非所问，查 Prompt 模板。

> 关键原则：**先分召回和生成两层，再看最终答案**。只看最终答案对不对，定位不到问题在哪一环。
